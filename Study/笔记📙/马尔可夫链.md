# 马尔可夫链 (Markov Chain) 核心学习笔记
## 1. 核心概念与马尔可夫性质
马尔可夫链是描述一种状态序列的随机过程，其最核心的特征是**无后效性（马尔可夫性质, Markov Property）**。
**定义：**
在给定当前状态及其所有过去状态的情况下，其未来状态的条件概率分布仅依赖于当前状态，而与过去的状态无关。
用数学语言表达即为：

$$P(X_{t+1} = x \mid X_t = x_t, X_{t-1} = x_{t-1}, \dots, X_0 = x_0) = P(X_{t+1} = x \mid X_t = x_t)$$ ^03ce3e

可以通俗地理解为：“已知现在，未来与过去无关。”

## 2. 数学表达：状态空间与转移矩阵
要完整定义一个马尔可夫链，通常需要两个核心要素：
### 2.1 状态空间 (State Space, $\mathcal{S}$)
系统所有可能处于的状态的集合。例如 $\mathcal{S} = \{s_1, s_2, \dots, s_N\}$。在离散马尔可夫链中，状态空间是有限或可列无限的。
### 2.2 状态转移矩阵 (Transition Matrix, $\mathbf{P}$)
描述系统从一个状态转移到另一个状态的概率。对于有限状态空间，转移概率构成一个矩阵 $\mathbf{P}$，其中第 $i$ 行第 $j$ 列的元素 $P_{ij}$ 表示在时间 $t$ 处于状态 $i$，在时间 $t+1$ 转移到状态 $j$ 的概率：
$$P_{ij} = P(X_{t+1} = j \mid X_t = i)$$

**转移矩阵的性质：**
- 非负性：$P_{ij} \ge 0$
- 行和为 1（每一行构成一个概率分布）：$\sum_{j \in \mathcal{S}} P_{ij} = 1$

### 2.3 状态分布的演化
设 $\pi_t$ 为时间 $t$ 的系统状态概率分布（一个行向量，第 $i$ 个元素为处于状态 $i$ 的概率），则下一时刻的状态分布可由矩阵乘法得出：
$$\pi_{t+1} = \pi_t \mathbf{P}$$

经过 $n$ 步的转移后，状态分布为：
$$\pi_{t+n} = \pi_t \mathbf{P}^n$$

## 3. 核心性质：平稳分布 (Stationary Distribution)
在经历足够长时间的演化后，许多马尔可夫链的状态概率分布会趋于稳定，不再随时间变化。这个稳定的分布称为平稳分布，记为 $\pi$。
**定义方程：**
$$\pi = \pi \mathbf{P}$$

_(注：从线性代数的角度看，平稳分布 $\pi$ 就是状态转移矩阵 $\mathbf{P}^T$ 对应于特征值 $\lambda = 1$ 的归一化特征向量。)_
**存在与唯一性条件：**
如果一个马尔可夫链是**不可约的（Irreducible）**（任意两个状态之间互相可达）且是**非周期的（Aperiodic）**，并且是**正常返的（Positive Recurrent）**，那么该马尔可夫链被称为**遍历的（Ergodic）**，它必定存在唯一的平稳分布。
**细致平稳条件 (Detailed Balance)：**
如果存在一个分布 $\pi$ 满足：
$$\pi_i P_{ij} = \pi_j P_{ji} \quad \forall i, j \in \mathcal{S}$$
则该马尔可夫链满足细致平稳条件，此时 $\pi$ 必定是该链的平稳分布。（此性质是马尔可夫链蒙特卡洛方法 MCMC 的核心基础）。

## 4. 进阶延伸：通向强化学习与最优控制的基石
纯粹的马尔可夫链仅描述了状态的自由演化。当我们在其中引入**奖励（Reward）**和**动作/控制（Action）**时，它便演化成了现代决策算法的核心环境模型。
- **马尔可夫奖励过程 (Markov Reward Process, MRP):**
    在马尔可夫链的基础上加入奖励函数 $R_s$ 和折扣因子 $\gamma$。这引入了价值函数（Value Function）的概念：$$V(s) = \mathbb{E} [G_t \mid S_t = s] = \mathbb{E} [R_{t+1} + \gamma V(S_{t+1}) \mid S_t = s]$$
- **马尔可夫决策过程 (Markov Decision Process, MDP):**
    在 MRP 基础上加入动作集合 $\mathcal{A}$。状态转移概率和奖励不再仅仅取决于当前状态，而是取决于当前的“状态-动作”对 $(s, a)$：$P(s' \mid s, a)$。求解 MDP 中的最优策略（如使用贝尔曼最优方程），正是 Q-Learning、SAC、PPO 等算法的理论底层。
- **多智能体扩展 (Stochastic Games / Markov Games):**
    当引入多个并发执行动作的主体时，状态的转移概率变为 $P(s' \mid s, a_1, a_2, \dots, a_n)$。这是研究复杂协同控制、博弈逻辑以及基于 Actor-Critic 架构的分布式算法（如 MADDPG）的基础数学抽象。
