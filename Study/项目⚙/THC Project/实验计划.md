## 参考自变量
- **当前室温 (T)** 
- **目标室温 (T_target)**
- **当前室内湿度 (H)**
- **目标室内湿度 (H_target)**
- **温度差异 (Delta T)**：当前室温和目标室温之间的差值
- **湿度差异 (Delta H)**：当前室内湿度与目标湿度之间的差值
- **温度变化率 (dT/dt)**：单位时间内温度的变化量，可以揭示温度变化的趋势和速度
- **湿度变化率 (dH/dt)**：单位时间内湿度的变化量，同样用于识别湿度变化的动态
- **温度偏差 (T_deviation)**：当前室温与历史平均室温的偏差，可能反映季节性或日常模式的变化
- **湿度偏差 (H_deviation)**：当前湿度与历史平均湿度的偏差，类似地反映季节性或日常模式
- **温度-湿度交叉项 (T\*H)**：温度与湿度的乘积，可以捕捉两者相互作用对设备效率的影响
- **室外温度 (T_outside)**：外部环境的温度可能影响室内温度的自然变化 
- **室外湿度 (H_outside)**：同理，室外湿度也会影响室内湿度的变化趋势
- **室外温湿度与室内温湿度的差值 (Outdoor-Indoor Delta T/H)**：表示内外部环境的差异，可能影响设备的工作负荷
- **时间 (Time of Day/Season)**：一天中的时间和季节可能影响室内温度和湿度的自然波动，以及设备的效率
- **设备运行状态 (Status of HVAC appliances)**：即制冷、制热、加湿、除湿、风扇是否开启
- **设备历史运行时间 (Run Time History)**：设备过去一段时间的运行状态，有助于预测其当前的效率和能耗和潜在的维护需求
- **设备老化系数 (Aging Factor)**：设备使用年限和磨损程度可能影响其效率
- **设备工作时间比率 (Appliance Run Ratio)**：设备在一定时间内的运行时间比例，反映设备的使用频率
- **设备切换频率 (Appliance Switch Frequency)**：单位时间内设备开关次数，可能影响设备的寿命和效率
- **能耗预测 (Energy Consumption Prediction)**：基于历史数据预测下一时间步长的能耗
- **季节性指标 (Seasonal Indicator)**：如夏季、冬季标识，反映季节性影响下的设备效率变化

## 实验一 - 不同温湿度下设备能耗以及工作效率记录
#### 实验目的
记录不同温湿度环境下，设备的能耗差异和对环境温湿度影响的差异，以及设备全部关闭时在各个特征下的温室度变化。
用于预测控制过程中当前温湿度环境下开启设备一个$\Delta t$后会产生的能耗以及对环境温湿度产生的影响
#### 实验设置
1. 假设环境内温度调节范围为$[min_T,max_T]$，湿度调节范围为$[min_H,max_H]$将温湿度调节范围平均分为n个采样点。
2. 调节温度和湿度至采样点后关闭所有设备。依次单独开启制冷机、制热机、加湿机、除湿机、风扇，记录开启设备一个时间间隔$\Delta t$后产生的能耗以及对环境温湿度产生的影响。
3. 每当一个设备记录完成后需要将环境温湿度恢复至采样点。直至所有设备完成该采样点的采样，调整环境温湿度至下一个采样点，重复步骤2、3。
#### 实验预期
能够得到至少$n \times n$ 个不同温湿度环境下各个设备的能耗以及对环境温湿度产生的影响
#### 实验优化
对于能耗变化较大的采样点之间可以细分几个采样点进行采样，使最终拟合的数据更加准确


## 实验二 - 设备开启后能耗随开启时间的变化
#### 实验目的
验证设备能耗是否会受设备工作时长影响，如有，会对能耗预测模型预测准确度产生一定的影响。需测量不同开始时长后$\Delta t$的能耗，并判断一定时长后能耗是否收敛
#### 实验设置
1. 设定一个考察时长T，可为2小时；设定环境温湿度为定值
2. 开启设备A记录其能耗变化，并且调整其他设备状态使房间内温湿度保持稳定
3. 开启时间到达考察时长T后，观察记录能耗数据，若后期能耗波动依然较大，则加时1小时
4. 对每台设备进行步骤2、3操作，记录时长不超过$T_{max}$，$T_{max}$暂定为6小时
#### 实验预期
能够检验设备工作时长对设备能耗的影响，并评估影响大小。
#### 实验优化
可以视实验结果进行优化

## 实验三 - 设备同时开启和分时开启的能耗差异
#### 实验目的
验证多台设备同时开启和分别开启的总能耗是否相同，如有不同，则此处差异会对能耗预测模型准确度产生影响。需要评估两种启动方式的能耗差异大小和对模型预测结果准确度的影响大小
#### 实验设置
1. 设定环境温湿度为定值
2. 开启设备A，记录一个$\Delta t$后设备A的能耗
3. 调整环境温湿度为设定环境温湿度
4. 开启设备B，记录一个$\Delta t$后设备B的能耗，并与设备A能耗相加得到分时开启总能耗
5. 调整环境温湿度为设定环境温湿度
6. 同时开启设备A、设备B，记录一个$\Delta t$后两台设备的总能耗得到同时开启总能耗
7. 进行对比和评估
#### 实验预期
验证设备同时开启和分时开启是否会有较大能耗差异，能够评估这部分差异对能耗预测模型是否会产生较大影响
#### 实验优化
可以视实验结果进行优化
