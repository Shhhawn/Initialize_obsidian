# Obsidian 与 Markdown 基础入门指南 (macOS 版)
欢迎使用 Obsidian！Obsidian 是一款基于本地 Markdown 文件的强大双向链接笔记软件。掌握它的基础操作和 Markdown 语法，将极大提升您的知识管理效率。
## 第一部分：Obsidian 基础操作 (macOS)
在 macOS 系统下，Obsidian 的快捷键主要依赖于 `Cmd (⌘)` 键。以下是日常使用中最核心的操作：
### 1. 核心概念：库 (Vault)
Obsidian 中的“库”本质上就是您电脑上的一个**本地文件夹**。您的所有笔记都会以 `.md`（Markdown）格式保存在这个文件夹中，完全归您本地掌控，无需担心云端数据锁定。
### 2. 工作区介绍及 Mac 常用高频快捷键
工作区介绍
![[Pasted image 20260424125714.png]]
快捷键介绍：
- 命令面板 (最重要)：`Cmd + P` （几乎可以通过它执行 Obsidian 的所有操作，强烈建议多用）
- 新建笔记：`Cmd + N`**（不常用）**
- 快速切换/打开笔记：`Cmd + O`**（常用，也可以用于新建笔记）**
- 在所有笔记中搜索：`Cmd + Shift + F`
- 切换侧边栏：`Cmd + B` （展开/收起左侧边栏）
- 切换阅读/编辑模式：`Cmd + E` （在源码模式和渲染后的阅读模式之间切换）
- 关闭当前标签页：`Cmd + W`

### 4. Obsidian 灵魂功能：双向链接 (Bi-directional Links)
双向链接是 Obsidian 将零散笔记织成知识网的关键。
- **操作方法**：在任意位置输入两个左中括号 `[[`，Obsidian 会自动弹出您库中的笔记列表。
- **效果**：选择或输入笔记名称后（例如 `[[学习笔记]]`），这两篇笔记之间就建立了关联，**点击链接即可跳转**（不跳转的查看方式在下面）
- 可以点击左侧工具栏**查看关系图谱**看到所有笔记之间的链接
   ![[Pasted image 20260424103601.png]]

如果不想链接到整篇笔记，想要更精细化一点，可以：
- 使用 `#` 链接到标题，如 `[[马尔可夫链#1. 核心概念与马尔可夫性质]]`：[[马尔可夫链#1. 核心概念与马尔可夫性质]]
- 使用 `^` 链接到一块文字，如 `[[马尔可夫链#^03ce3e]]`:  [[马尔可夫链#^03ce3e]]
- 也可以添加 `|` 指定链接的显示文本，格式为 `[[笔记名|显示的文本]]`，如 `[[马尔可夫链#1. 核心概念与马尔可夫性质 | 定义]]` 会显示为 [[马尔可夫链#1. 核心概念与马尔可夫性质 | 定义]]
上面三种技巧不需要记忆，可以在链接的时候看到提示 ******
![[Pasted image 20260424105433.png | 500]]


> [!note] 如何不跳转查看链接的内容
> - 通过按住 `cmd`，并将鼠标移动到链接之上，会弹出一个预览窗口，可以查看链接的内容

>   比如下面是 `![[马尔可夫链#1. 核心概念与马尔可夫性质]]` 的显示效果：
>   ![[马尔可夫链#1. 核心概念与马尔可夫性质]]
> - 其实可以发现，obsidian 笔记中的图片就是以 `![[图片文件名]]` 的方式插入在笔记中的，**图片的链接中在 `|` 后面添加数字可以调整图片大小**

## 第二部分：Markdown 基础语法
Markdown 是一种轻量级标记语言，它允许我们使用易读易写的纯文本格式编写文档。
> **说明**：以下语法演示均遵循“先展示源码（代码块内），后展示渲染效果”的规则。
### 1. 标题和分割线 (Headers)
使用 `#` 号加上一个空格来表示标题。`#` 的数量代表标题的级别（最多支持六级）。
使用 `---` 表示分割线（如果显示出错，在分割线前后分别输入一个换行试试）
**语法：**
``` markdown
# 这是一级标题
## 这是二级标题
### 这是三级标题

---
上面是分割线
```
# 这是一级标题
## 这是二级标题
### 这是三级标题

---
上面是分割线

---

### 2. 文本加粗、斜体和高亮 (Emphasis)
使用星号 `*` 或下划线 `_` 和等号 `=` 来强调文本。
**语法：**
``` markdown
**这是加粗文本**
*这是斜体文本*
***这是加粗且斜体的文本***
~~这是带有删除线的文本~~
==这是高亮文本==
```

**渲染效果：** **这是加粗文本** _这是斜体文本_ **_这是加粗且斜体的文本_** ~~这是带有删除线的文本~~ ==这是高亮文本==

---

### 3. 列表 (Lists)
分为无序列表和有序列表。无序列表使用 `-`、`+` 或 `*` 加空格；有序列表使用数字加英文句号 `.` 。
**语法：**
``` markdown
- 无序列表项 1
- 无序列表项 2
  - 缩进的子列表项

1. 有序列表项 1
2. 有序列表项 2
```

**渲染效果：**
- 无序列表项 1
- 无序列表项 2
    - 缩进的子列表项
1. 有序列表项 1
2. 有序列表项 2

---

### 4. 引用 (Blockquotes)
如果您需要引用一段文字，或高亮一段文字，可以在段落开头使用 `>` 符号加空格。
**语法：**
``` markdown
> 这是一段引用文字。
> Obsidian 真的很好用！
>> 这是嵌套的二级引用。
```
**渲染效果：**
> 这是一段引用文字。 Obsidian 真的很好用！
> 
> > 这是嵌套的二级引用。

#### Obsidian 中引用的高级用法
Obsidian 中可以通过添加不同的标签实现不同的标注块，比如显示 Note 的语法为：
``` markdown
> [!note]
```
**渲染效果：**
> [!note]
> 这是 Note 块

也可以在 `[!note]` 后面添加标题，如
``` markdown
> [!note] 这是Note块
```
**渲染效果：**
> [!note] 这是 Note 块

其他标注块用法详见[[标注块]]

**语法：**

### 7. 任务列表 (Task Lists)
任务列表非常适合用来做待办事项 (To-Do List)。使用 `- [ ]` 表示未完成，`- [x]` 表示已完成（注意括号中间有空格）。在 Obsidian 的阅读模式下，您甚至可以直接点击方框来勾选任务。
**语法：**
``` markdown
- [ ] 学习 Obsidian 快捷键
- [ ] 熟悉 Markdown 语法
- [x] 安装并启动 Obsidian
```

**渲染效果：**
- [ ] 学习 Obsidian 快捷键
- [ ] 熟悉 Markdown 语法
- [x] 安装并启动 Obsidian

### 8. 公式（比较复杂，可以让大模型生成）
#### 1. 公式类型
在 Markdown 中，公式分为**行内公式**和**行间（块状）公式**。
##### 行内公式 (Inline Math)
将公式嵌入在文本段落中。
**语法：**
``` markdown
能量守恒定律公式为：$E = mc^2$。
```
**渲染效果：**
能量守恒定律公式为：$E = mc^2$。

##### 行间公式 (Display Math)
公式独立成行，且通常会居中显示。
**语法：**
``` markdown
$$
\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}
$$
```
**渲染效果：**
$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$$
#### 2. 基础符号
##### 上标与下标 (Superscripts & Subscripts)
使用 `^` 表示上标，使用 `_` 表示下标。如果上下标内容超过一个字符，需用 `{}` 包裹。
**语法：**
``` markdown
$x^2$ , $a_i$ , $10^{n+1}$, $r_{t+1}$
```
**渲染效果：**
$x^2$ , $a_i$ , $10^{n+1}$, $r_{t+1}$
##### 分式与根号 (Fractions & Roots)
使用 `\frac{分子}{分母}` 表示分式，`\sqrt{内容}` 表示根号。
**语法：**
``` markdown
$\frac{a}{b}$ , $\sqrt{x}$ , $\sqrt[n]{x}$
```

**渲染效果：**
$\frac{a}{b}$ , $\sqrt{x}$ , $\sqrt[n]{x}$
##### 希腊字母 (Greek Letters)
直接使用反斜杠 `\` 加上字母的英文名称。首字母大写通常代表大写形式。
**语法：**
``` markdown
$\alpha$ , $\beta$ , $\gamma$ , $\theta$ , $\pi$ , $\Delta$ , $\Omega$
```

**渲染效果：**
$\alpha$ , $\beta$ , $\gamma$ , $\theta$ , $\pi$ , $\Delta$ , $\Omega$
#### 3. 运算符与修饰符
##### 累加、累乘与积分 (Operators)
这些符号在行间模式下会自动调整上下标的位置。
**语法：**
``` markdown
$$
\sum_{i=1}^n x_i \quad \prod_{i=1}^n y_i \quad \int_0^\infty f(x) dx
$$
```

**渲染效果：**
$$\sum_{i=1}^n x_i \quad \prod_{i=1}^n y_i \quad \int_0^\infty f(x) dx$$
##### 关系运算符
常用的比较和等价符号。
**语法：**
``` markdown
$\approx$ , $\neq$ , $\le$ , $\ge$ , $\infty$ , $\forall$ , $\exists$
```

**渲染效果：**
$\approx$ , $\neq$ , $\le$ , $\ge$ , $\infty$ , $\forall$ , $\exists$

#### 4. 矩阵与向量
对于多行、多列的数据，使用 `matrix` 环境。常见的有 `pmatrix`（圆括号）、`bmatrix`（方括号）。
**语法：**
``` markdown
$$
A = \begin{bmatrix}
1 & 0 \\
0 & 1
\end{bmatrix}
$$
```

**渲染效果：**

$$A = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$
#### 5. Obsidian 使用小贴士
1. **实时预览**：Obsidian 默认开启实时预览，你输入完 `$` 符号并完成公式后，光标移开即可看到渲染结果。
2. **公式颜色**：你可以使用 `\color{red}{公式内容}` 来改变颜色。
3. **多行公式对齐**：可以使用 `aligned` 环境配合 `\\` 分行和 `&` 符号进行对齐，渲染后，公式会自动将用 `\\` 隔开的不同行中的 `&` 对齐。

**对齐语法示例：**
``` markdown
$$ 
\begin{aligned}
(a+b)^2 &= a^2 + ab + ba + b^2 \\
 &= a^2 + 2ab + b^2
\end{aligned}
$$
```

**渲染效果：**
$$ 
\begin{aligned}
(a+b)^2 &= a^2 + ab + ba + b^2 \\
 &= a^2 + 2ab + b^2
\end{aligned}
$$
